TMDB

Reko browses TMDB, so it needs a TMDB API Read Access Token. The token is only ever used by the Jellyfin server; it is never sent to a browser.

Create one at themoviedb.org/settings/api. Use the API Read Access Token, not the older API key.

Overseerr / Jellyseerr

Optional. Reko can submit requests for titles that are not in your library, with a season picker for series and live request status.

In Seerr, open your avatar, choose Settings → General → API Key and click Show API Key. Needs the X-Api-Key permission set to Admin so requests are attributed correctly.
Maps each Jellyfin account to its Seerr account so request quotas and history are personal. If CSRF protection is enabled in Seerr, turn it off: Seerr rejects API-key requests with invalid csrf token otherwise.

Home tab

A comma separated list of row ids, for example top10-today,trending-movies,action-adventure. Any row you leave out is appended at the end rather than removed. Leave blank for the default order.

Title pages

The YouTube player is only loaded when you press play, so nothing is fetched from Google until you do.

Caching and diagnostics

Rails are cached so a row costs one TMDB request no matter how many users open the tab. TMDB returns no rate limit headers, so Reko budgets its own requests.
How long a computed profile of your viewing history is reused. It is the most expensive thing Reko computes, so it is cached separately and for much longer than the rows.
